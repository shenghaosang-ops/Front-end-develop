# Front-end-develop
a front-end page design for navigating to a different web page

## 网址跳转路径说明 / URL Navigation Path

服务卡片的跳转网址配置在 `src/pages/HomePage.tsx` 文件的 `services` 数组中。用户可以通过修改该数组中每个服务对象的 `link` 字段，来实现跳转到不同的网址。

The navigation URLs for the service cards are configured in the `services` array in `src/pages/HomePage.tsx`. You can change the destination of each card by editing the `link` property in this array.

## 前端技术栈 / Frontend Tech Stack

本项目基于以下前端技术实现：
- React 18
- TypeScript
- Ant Design 组件库
- CSS 自定义样式

This project is built with:
- React 18
- TypeScript
- Ant Design UI library
- Custom CSS styling
